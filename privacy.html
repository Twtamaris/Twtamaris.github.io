autoclip privacy policy

Last updated: 2026-11-04

What autoclip is

autoclip is a personal tool run by a single owner on their own computer or server. It is not offered to the public.

What access it requests

With the owner's explicit consent through Google sign-in, autoclip requests access to the owner's own YouTube account to:

  • upload videos to the owner's channel (youtube.upload);
  • read basic channel and video information (youtube.readonly);
  • read the channel's analytics, such as views and watch time (yt-analytics.readonly).

How data is used and stored

The access token is stored only on the owner's own machine or server and is used only to perform the actions above. Analytics data is used only to decide which kinds of clips to make. autoclip does not collect data about any other people.

Sharing

autoclip does not sell, share, or transfer Google user data to anyone, and does not use it for advertising.

Google API Services User Data Policy

autoclip's use of information received from Google APIs adheres to the Google API Services User Data Policy, including the Limited Use requirements.

Revoking access

The owner can revoke autoclip's access at any time at myaccount.google.com/permissions.

Contact

Questions can be sent through the owner's GitHub profile: github.com/Twtamaris.
